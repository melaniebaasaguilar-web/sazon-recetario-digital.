# Sazón — Recetario Digital

Aplicación web de recetas de cocina desarrollada como
proyecto académico utilizando HTML, CSS, JavaScript
y la API pública TheMealDB.

## Objetivo

Desarrollar una aplicación que permita consultar recetas
de cocina mediante una API externa, mostrando imágenes,
ingredientes e instrucciones de preparación.

## Funcionalidades

- Buscar recetas por nombre.
- Visualizar fotografías de los platillos.
- Consultar ingredientes y preparación.
- Guardar recetas favoritas.
- Conservar favoritos utilizando localStorage.
- Mostrar mensajes de carga y errores.
- Adaptarse a celulares y computadoras.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- TheMealDB API
- GitHub
- GitHub Pages

## Cómo ejecutar el proyecto

1. Descargar o clonar este repositorio.
2. Abrir el archivo index.html en un navegador.
3. Contar con conexión a Internet para consultar la API.
4. Buscar recetas por nombre, por ejemplo: chicken o pasta.

También puede utilizarse desde GitHub Pages:

https://melaniebaasaguilar-web.github.io/sazon-recetario-digital/
